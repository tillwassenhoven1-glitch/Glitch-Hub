# 🎮 Glitch-Hub

**Alle meine Browser-Spiele an einem Ort.**
Kein Durchklicken durch GitHub-Links mehr: Thumbnail anklicken, Beschreibung lesen, liken – und los geht's.

**Version 0.1 · Open Beta**

---

## ✨ Features

- 🖼️ **Spiele-Übersicht** im matten Schwarz-Look, wie bei Crazy Games
- 🗂️ **Kategorien** links: Autospiele, Sportspiele, Denkspiele, Action, Casino & Sim, Multiplayer
- 🔍 **Suche** oben links
- 👤 **Konto** mit Name + Passwort
- 👍👎 **Likes & Dislikes**, für alle sichtbar
- 🔥 **Beliebt**: die Spiele mit den meisten Likes ganz oben
- 📱 Läuft auf **PC, Handy und Tablet**
